# Profile dropdown added as a decorative placeholder; notifications skipped

The sample shell includes both a notification bell and a profile-avatar dropdown. Zeteo has no auth/user-identity system defined in the URS yet, so we added only the profile dropdown (placeholder initials avatar, inert "Your profile / Settings / Sign out" items) to complete the shell's visual footprint, and skipped the notification bell entirely rather than imply a notifications feature that doesn't exist anywhere in scope.

**Status**: accepted
