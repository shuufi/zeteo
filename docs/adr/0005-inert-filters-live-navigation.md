# Filters are decorative; breadcrumb and drill-down navigation are functional

The wireframe shows several chip rows that look like filters — Business/Period/vs Budget in the context bar, YTD/MTD/QTD, Segment-by, and the Petroleum/Gas/Offshore compare row. None of them change the mock data in this prototype: they render (so the layout and IA read correctly) but clicking them does nothing. Everything that is actual IA navigation — breadcrumb chips, KPI card / exception / driver-row links, VDT Explorer row and tree-node clicks, and Driver Diagnostic tab switches — is fully wired through `svelte-spa-router` so the click-through story in `docs/URS_Zeteo_v2.2.md` section 2.5.1 (Home → VDT Explorer → Driver Diagnostic → Benchmark → Root Cause) can be demonstrated end to end.
